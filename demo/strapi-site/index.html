Sample Storefront

A plain website that reads its copy straight from Strapi — no API token in this page, just the CMS's public read permissions. Push a translation from content-provenance and refresh to see it land here, provenance and all.

How to test the full loop

1. Create a translation in content-provenance (or reuse one you already have).
2. Push it into one of the entries below via POST /api/v1/integrations/cms/push.
3. Click Refresh — the storefront card updates with the new text, and the "Provenance" panel fills in with what content-provenance recorded about it.
